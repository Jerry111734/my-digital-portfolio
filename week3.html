Weekly reflection · WEEK 3

Web Scraping

Experimenting with methods for collecting information from websites.

What I explored

The Week 3 activity introduced web scraping through WebScraper.io. I worked with character pages on Marvel’s official website, using a familiar collection of web pages to think about how information can be gathered in a structured way.

The important practical question was which elements of a page should become data. For example, a character name, a link to a profile and a piece of descriptive text would be different fields; collecting one field consistently is not the same as copying everything visible on a page.

Why the structure matters

I began to understand that a website is designed for visitors, not necessarily for researchers who want a neat dataset. Layout changes, missing information and repeated sections could make scraping inconsistent. The fields a researcher chooses will also decide what kinds of questions the resulting data can answer.

I should check the collected information against the original pages and record what each field means before using it for analysis. This page describes the workshop exercise; it does not claim a verified final number of scraped records.

My reflection on responsible collection

Scraping can make data collection faster, but it does not remove the need for judgement. Information being visible online does not automatically mean it should be reused without considering source rules, attribution and privacy.

This exercise also connects to my interest in Marvel: even when I recognise the subject matter, I still have to evaluate the data collection method instead of relying on my familiarity with the characters.

What I would improve

For a future scraping task, I would define the fields before collecting data, test the method on a small number of pages and check for missing or duplicated entries before drawing conclusions.
