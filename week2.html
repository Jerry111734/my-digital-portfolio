Weekly reflection · WEEK 2

Creating and Hosting a Website

Learning the foundations of web development and online publishing.

What I learned

This week focused on the basic structure of websites and the relationship between HTML and CSS. HTML provides the structure and content of a page, while CSS controls its visual presentation.

Practical experience

I worked with HTML to create web pages and used CSS to experiment with layout, colours, typography and responsive design. I also learned how to publish a website using GitHub Pages, connecting the files in a repository to a live website.

My reflection

Building a website made the process of digital publishing feel more tangible. Small changes to the code could affect the way a page looked and how a visitor moved through it. I also began to understand that a website is not just a single page: navigation, consistency and accessibility all contribute to the experience.

What I want to improve

I want to become more confident in organising HTML and CSS, keeping the design consistent across pages and checking that the site works on different screen sizes.
