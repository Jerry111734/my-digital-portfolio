# My Digital Media Portfolio

A responsive static website for the University of Leeds Digital Media portfolio.

## Files
- `index.html` — homepage
- `reflection.html` — weekly reflection index
- `week1.html` to `week5.html` — individual workshop pages
- `style.css` — shared responsive styling

## Publishing
The site is designed for GitHub Pages. Keep all HTML files and `style.css` in the repository root so the relative links work.

## Important content note
The pages are drafted from the workshop details and activities available in the existing portfolio. Please review the wording of personal reflections and adjust any sentence that does not accurately represent your own experience before submission.
