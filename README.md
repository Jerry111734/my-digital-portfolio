# My Digital Media Portfolio — Polished Copy

This is an improved, self-contained copy of the University of Leeds digital media portfolio, based on the GitHub source reviewed on 23 November 2026.

## Contents
- `index.html` — homepage
- `reflection.html` — weekly reflections index
- `week1.html` to `week5.html` — existing reflections, with their original prose preserved
- `style.css` — responsive styling, accessible keyboard focus, mobile navigation, reduced-motion and print support

## Improvements
- Skip-to-content link and current-page navigation labels
- Previous/next week buttons on every reflection page
- Enhanced mobile styles, keyboard focus indicators, and print styles
- Original workshop prose retained; no fabricated results or unpublished datasets added

## How to publish
1. Open the `Jerry111734/my-digital-portfolio` repository on GitHub.
2. Upload the files in this ZIP into the **repository root** (not into a nested folder).
3. Confirm replacing the matching files, commit the changes to `main`, then reload GitHub Pages.
4. Review the personal first-person reflections yourself before submitting them for assessment.

The connected GitHub app could read the repository but received a 403 on write, so the original online repository has **not** been changed by this export.
