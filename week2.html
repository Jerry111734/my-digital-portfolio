Weekly reflection · WEEK 2

Creating and Hosting a Website

Learning the foundations of web development and online publishing.

What I worked on

I began building a portfolio website using HTML and CSS in Visual Studio Code. I worked with an index.html page and a stylesheet: HTML organised the headings, text and links, while CSS controlled colours, spacing and layout.

I then used a public GitHub repository and GitHub Pages to make the website accessible through a link. That process helped me see the difference between a page that works on my computer and one that works after publishing. File names and relative links matter because the published site has to find the same files.

A practical lesson about navigation

As the portfolio developed, I created a separate Reflections page and links between Home and the weekly pages. I encountered navigation issues, including links that did not jump to the intended page and an extra closing head tag in the HTML. I checked the page structure and corrected the links. These were experiences from continuing to build the portfolio, not necessarily all tasks completed during the Week 2 workshop.

The result is a portfolio with a homepage, a reflection index and individual weekly entries. It is useful to test a link by actually clicking it, rather than assuming it works because its code looks correct.

My reflection

I learned that making a website is partly about writing code and partly about guiding someone through information. A visitor should be able to find a reflection, move to another week and return to the homepage without confusion. A clean-looking page is not enough if its links do not work.

Next, I want to keep checking navigation on both desktop and mobile screens and make the content itself as clear as the layout.
